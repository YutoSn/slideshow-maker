# Slideshow Maker

写真を音楽のビートに合わせて切り替える、ブラウザ完結の音楽同期フォトスライドショー作成ツール。

素材はすべてブラウザ内で処理され、サーバーへは送信されません。

## できること

- **ビート検出** — 音源を解析して BPM・ビート位置・小節頭を自動で推定
- **ビート同期のカット割り** — 「1 枚あたり N 拍」で写真をビート格子にスナップして配置
- **Ken Burns / 拍に合わせた拡大** — ゆっくり寄る動きと、拍ごとの軽い拡大
- **4 種類のトランジション** — クロスフェード / スライド / ズーム / フラッシュ
- **タイムライン編集** — カットごとに尺（拍数）とトランジションを個別調整
- **動画書き出し** — WebM 動画としてダウンロード
- **解析結果の書き出し** — BPM・ビート位置を JSON で保存

## 使い方

```bash
npm install
npm run dev     # http://127.0.0.1:5173
```

1. 写真（JPEG / PNG）と音源（MP3 など）をドロップ
2. 「1 枚あたりの拍数」やトランジションを調整
3. プレビューで確認し、必要ならタイムラインでカットごとに微調整
4. 「動画を書き出す」で WebM を保存

### 写真の用意について

現状はローカルファイルを選ぶ方式です。Google ドライブの写真を使う場合は、
ドライブ側でダウンロードしてから読み込ませてください。
ブラウザから直接ドライブ API を叩くには別途 OAuth クライアントの設定が必要で、
現時点では対象外としています（`docs/` の作業手順書を参照）。

**HEIC はブラウザが表示できないため読み飛ばされます。** iPhone の写真は
JPEG に変換してから読み込ませてください。

## 仕組み

### ビート検出（`src/engine/beatDetect.ts`）

1. 音源をモノラル化し、2048 サンプル / ホップ 512 で STFT
2. **スペクトルフラックス**（正の変化分の総和）でオンセット包絡線を作る
   低域を厚めに重み付けし、対数圧縮して静かな箇所の立ち上がりも拾う
3. 移動平均を引いた適応的な閾値で正規化
4. 包絡線の**自己相関**から BPM を推定（70〜180 BPM）
   2・3・4 倍周期のスコアも加算し、倍/半テンポの取り違えを抑える
5. 位相（最初のビート位置）を全探索で決定
6. 4 拍を 1 小節として、オンセットが最も強い位相を小節頭とする

解析は数秒かかるため Web Worker で実行し、UI をブロックしません。

BPM の推定が外れた場合は、UI から手動で補正できます。

### 描画（`src/engine/renderer.ts`）

canvas に毎フレーム描画します。写真は縦横比を保ったまま画面を覆い（cover 相当）、
セグメントの種から決まる Ken Burns の始点・終点を補間します。
トランジション中は前後 2 枚を重ねて描きます。

### 書き出し（`src/engine/exporter.ts`）

`canvas.captureStream()` と音声を 1 本の MediaStream にまとめ、`MediaRecorder` で録画します。
実時間でしか録れないため、書き出しには曲の長さぶんの時間がかかります。

`MediaRecorder` の出力する WebM には総再生時間（Duration）が書かれておらず、
そのままではプレイヤーで長さが分からずシークできません。
`src/engine/webmDuration.ts` で EBML を解析し、`Segment > Info` に Duration を
差し込んでから保存しています。

## 開発用スクリプト

```bash
node scripts/analyze-check.mjs [音源パス]   # ビート検出だけを実ブラウザで確認
node scripts/e2e-check.mjs                  # 素材投入→解析→描画までの通し確認
node scripts/export-video.mjs               # 書き出しまで含めた通し確認
node scripts/make-demo-photos.mjs           # 動作確認用のダミー写真を生成
node scripts/check-webm-duration.mjs [動画]  # 書き出した WebM の総再生時間を確認
```

いずれも `npm run dev` を起動した状態で実行してください。

## リポジトリに含まれないもの

著作権のある音源とプライベートな写真は `.gitignore` で除外しています
（`assets/`, `out/`）。動作確認には `scripts/make-demo-photos.mjs` で
ダミー写真を生成できます。
