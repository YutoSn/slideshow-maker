# Slideshow Maker 使い方マニュアル

写真を音楽のビートに合わせて切り替える、スライドショー作成ツールです。
Google Chrome で動きます。写真も音源もパソコンの外には送られません。

---

## 1. 準備（最初の一回だけ）

### Node.js を入れる

このアプリを動かすのに必要です。

1. https://nodejs.org/ja を開く
2. 左側の **「LTS」** と書かれたボタンからダウンロード
3. ダウンロードしたファイルを開き、画面の指示どおり「次へ」で進める

すでに入っている場合は、この手順は飛ばして大丈夫です。

---

## 2. 開き方

### Windows の場合

フォルダの中の **`start.bat`** をダブルクリックするだけです。

- 黒い画面が出て、少しすると Chrome が自動で開きます
- **初回だけ** 準備に数分かかります（`npm install` が走ります）
- 二回目以降は数秒で開きます

### Mac の場合

ターミナルでこのフォルダを開き、次を実行します。

```bash
./start.sh
```

### ブラウザが自動で開かないとき

黒い画面に出ている次のアドレスを、Chrome のアドレス欄に貼り付けてください。

```
http://localhost:5173/
```

### 終わり方

黒い画面（ターミナル）で **Ctrl + C**（Mac は Control + C）を押します。
黒い画面を閉じるだけでも止まります。

> 黒い画面はアプリの本体です。閉じるとブラウザ側も動かなくなります。
> 作業中は開いたままにしてください。

---

## 3. 画面の見かた

画面は大きく 3 つに分かれています。

| 場所 | 名前 | 役割 |
|---|---|---|
| 左上 | **写真プール** | 使う写真を貯めておく場所 |
| 左下 | **見せ方を決める** | 切り替えの速さや動きの設定 |
| 右上 | **プレビュー** | 実際の見え方の確認と書き出し |
| 右下 | **タイムライン** | カット（1 枚ぶんの区間）の並び。ここで編集します |

---

## 4. 基本の流れ

### ステップ 1：写真と音源を入れる

左上の点線の枠に、**写真と音源をまとめてドラッグ＆ドロップ**します。
「写真を足す」「音源を選ぶ」ボタンからでも選べます。

- 写真は **JPEG / PNG**
- 音源は **MP3** など
- 写真はあとから何枚でも足せます

音源を入れると自動でビート解析が始まります（曲の長さにもよりますが数秒）。
終わると、タイムラインに BPM とカット数が表示されます。

> **iPhone の写真（HEIC）は使えません。**
> Chrome が HEIC を表示できないため、読み込み時に自動で読み飛ばされます。
> JPEG に変換してから入れてください。

### ステップ 2：ざっくり決める

左下の「見せ方を決める」で全体の雰囲気を決めます。

| 設定 | 何が変わるか | おすすめ |
|---|---|---|
| **1 枚あたりの拍数** | 写真が切り替わる速さ。小さいほどテンポよく切り替わる | 8 拍（ゆったり）／ 4 拍（テンポよく） |
| **トランジションの長さ** | 写真の重なる時間 | 1 拍 |
| **Ken Burns** | ゆっくり寄る・引く動きの強さ。0 で静止 | 12% |
| **拍に合わせた拡大** | 拍のたびに軽く弾む演出 | 4% |
| **トランジション** | 切り替え方。「おまかせ」は 4 種類を順番に混ぜる | おまかせ |
| **写真の順番をシャッフル** | 入れた順ではなくランダムに並べる | お好みで |

### ステップ 3：写真をカットに当てはめる

ここがこのツールの中心です。**プールに貯めた写真を、好きなカットに当てはめられます。**

やり方は 2 通りあります。

**やり方 A：クリックで順に当てはめる（たくさん割り当てるとき向き）**

1. タイムライン下のカットを 1 つクリックして選ぶ（青い枠がつきます）
2. 左の写真プールで、使いたい写真をクリック
3. そのカットに割り当てられ、**選択が自動で次のカットに進みます**
4. あとは写真をクリックしていくだけで、順に埋まっていきます

**やり方 B：ドラッグして落とす（狙ったカットに入れるとき向き）**

写真プールの写真を、タイムラインのカットまでドラッグして離します。
落とせるカットは緑色に光ります。

**便利な表示**

- まだ 1 度も使っていない写真には **「未」** バッジがつきます
- 「未使用の写真だけ表示」にチェックを入れると、残りだけが並びます
- カットの左上の数字は、先頭から数えたカット番号です

### ステップ 4：カットごとに微調整する

カットを選ぶと、左下の「選択中のカット」で個別に調整できます。

- **− 1 拍 / + 1 拍** … そのカットの長さを変えます（以降のカットは自動でずれます）
- **トランジション** … そのカットの切り替え方だけ変えます
- **このカットを自動に戻す** … 手を加えた内容を取り消します

> **手で編集した内容は、上の設定を変えても消えません。**
> 「1 枚あたりの拍数」を変えてカット割りをやり直しても、
> 割り当てた写真はそのまま残ります。
> 全部やり直したいときは「手編集をすべて取り消す」を押してください。

### ステップ 5：確認する

- プレビュー画面をクリックすると再生・一時停止します
- タイムラインの波形部分をクリックすると、その位置に飛べます
- カットをクリックすると、そのカットの頭から確認できます

波形の**青い縦線が小節の頭**、細い線が拍です。写真の切り替わりがここに揃います。

### ステップ 6：動画にする

1. 画質を選ぶ（選択肢に、その曲の長さでのだいたいのファイルサイズが出ます）
2. **「動画を書き出す」** を押す
3. 終わると `slideshow.webm` がダウンロードされます

| 画質 | 大きさ | 目安 |
|---|---|---|
| 高画質（720p） | 大きい | 保存用・テレビで見る |
| 標準（720p） | ふつう | ふだんはこれ |
| 軽量（540p） | 小さい | LINE やメールで送る |

> **書き出しには曲の長さと同じだけ時間がかかります。**
> 5 分の曲なら約 5 分です。実際に録画しているためで、途中で
> タブを切り替えたり画面を閉じたりしないでください。
> 途中でやめたいときは「中止」を押します。

## 5. 困ったときは

**写真を入れたのに枚数が増えない**
HEIC 形式かもしれません。読み飛ばした枚数がオレンジ色のお知らせに出ます。
JPEG に変換してから入れ直してください。

**切り替わりが曲とズレている気がする**
曲によってはテンポの推定が半分／倍になることがあります。
左下の「BPM を手で直す」に正しい数字を入れると直ります。
（例：実際が 120 なのに 60 と出ている → 120 と入力）

**書き出した動画が再生できない**
WebM 形式です。Chrome にファイルをドラッグすれば再生できます。
Windows の「フォト」アプリでも開けます。

**ファイルが大きすぎて送れない**
画質を「軽量（540p）」にして書き出し直してください。

**黒い画面に赤い文字が出た**
`npm install` が途中で失敗していることが多いです。
黒い画面を閉じて、もう一度 `start.bat` をダブルクリックしてください。

---

## 6. 覚えておくと便利なこと

- 写真も音源もパソコンの外には出ません。ブラウザの中だけで処理されます
- ページを再読み込みすると内容は消えます。書き出しは済ませてから閉じてください
- 「解析結果を保存」を押すと、検出した BPM とビート位置を JSON で残せます
- Google ドライブの写真を使うときは、いったんパソコンにダウンロードしてから読み込ませてください
